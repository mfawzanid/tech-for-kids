Rock Paper Scissors

A Coding Tutorial for Kids (Ages 5-8)

⏱ ~45 minutes 📘 JavaScript 👶 Ages 5-8

Welcome! In this tutorial, you and your child will build a Rock Paper Scissors game together — the one you can actually play in the browser! No coding experience needed.

We've already prepared everything that makes the game look and feel complete: the buttons, the colors, the countdown animation, and all the wiring between them. Open game.js and you'll find the starter code waiting with 5 TODO functions — these are the game's brain, and that's what you'll build:

1. getWinner() — decides who wins each round
2. updateScore() — shows the score on screen
3. showResult() — reveals the computer's choice and the result
4. playAgain() — clears the screen for another round
5. resetAll() — resets everything back to zero

Each module below guides you through one function. After Module 3, the game comes alive — you can play!

1 getWinner()

Goal: Teach the computer the rules of Rock Paper Scissors!

Find the getWinner function in game.js. Replace the TODO with this code:

function getWinner(player, computer) {
    if (player === computer) return 'tie';
    if (
        (player === 'rock' && computer === 'scissors') ||
        (player === 'paper' && computer === 'rock') ||
        (player === 'scissors' && computer === 'paper')
    ) {
        return 'player';
    }
    return 'computer';
}
Explain to Kids: "This function decides who wins! If both pick the same, it's a tie. Rock beats scissors, scissors beats paper, paper beats rock. The function returns 'player' if you win, 'computer' if the computer wins, or 'tie' if it's a draw."
Try It! The game won't work yet — we need showResult() to use this function. That's coming soon!
Challenge: Can you explain why player === 'rock' && computer === 'scissors' means the player wins?

2 updateScore()

Goal: Show the score on the screen!

Find the updateScore function. Replace the TODO with this:

function updateScore() {
    document.getElementById('score').textContent =
        'Wins: ' + wins + ' | Losses: ' + losses + ' | Ties: ' + ties;
}
Explain to Kids: "This function puts the score on the screen! It takes the wins, losses, and ties numbers and displays them on the page. Our other functions will call updateScore() whenever the score changes."
Try It! Still not working yet. We need one more function to connect everything together!
Challenge: Can you change the text from "Wins" to "Victories"? What happens?

3 showResult()

Goal: Show the computer's choice and the result!

Find the showResult function. Replace the TODO with this:

function showResult() {
    const winner = getWinner(playerChoice, computerChoice);

    document.getElementById('computer-emoji').textContent = getEmoji(computerChoice);

    if (winner === 'player') {
        wins++;
    } else if (winner === 'computer') {
        losses++;
    } else {
        ties++;
    }

    updateScore();

    const centerEl = document.getElementById('center');
    if (winner === 'player') {
        centerEl.textContent = '🎉 You Win!';
    } else if (winner === 'computer') {
        centerEl.textContent = '😢 You Lose!';
    } else {
        centerEl.textContent = '🤝 It\'s a Tie!';
    }

    setButtonsDisabled(false);
    isPlaying = false;
}
Explain to Kids: "This is the big one! showResult() combines everything we've built: it uses getWinner() to figure out who won, updates the score, and shows the result in the middle of the screen. It also re-enables the buttons so you can play again!"
Try It! NOW the game works! Pick rock, paper, or scissors and watch the countdown and result! The score even updates after each round.
Challenge: Can you change the win message from "🎉 You Win!" to something funnier like "🎉 You're Awesome!"?

4 playAgain()

Goal: Clear the screen so you can play another round!

Find the playAgain function. Replace the TODO with this:

function playAgain() {
    document.getElementById('player-emoji').textContent = '';
    document.getElementById('computer-emoji').textContent = '';
    document.getElementById('center').textContent = '';
}
Explain to Kids: "This function clears everything on the screen so you're ready for the next round. It empties the player emoji, the computer emoji, and the center message. But notice — it does NOT reset the score! Your wins and losses stay."
Try It! Play a few rounds, then click "Play Again." The screen clears, but your score is still there. Now play another round!
Challenge: What happens if you click "Play Again" during the countdown?

5 resetAll()

Goal: Reset everything and start a fresh game!

Find the resetAll function. Replace the TODO with this:

function resetAll() {
    wins = 0;
    losses = 0;
    ties = 0;
    document.getElementById('player-emoji').textContent = '';
    document.getElementById('computer-emoji').textContent = '';
    document.getElementById('center').textContent = '';
    updateScore();
}
Explain to Kids: "This function does a complete reset! It sets wins, losses, and ties back to zero, clears the screen, and calls updateScore() to show the new score of 0-0-0. It's like pressing the reset button on a video game!"
Try It! Play several rounds to build up a score. Now click "Reset All" — everything goes back to zero! Then play again to make sure the game still works.
Challenge: Can you add a confirmation popup that asks "Are you sure?" before resetting?
